# Privacy Policy

Effective date: September 15, 2026

Natural Science Learning Design is a skills-only plugin. It does not operate an external server, require an external account, use third-party analytics, or independently collect, store, sell, or transmit personal information.

Teachers may provide lesson plans and classroom context to ChatGPT or Codex when using the plugin. That content is processed by the OpenAI product through which the plugin is used and is subject to the user's applicable OpenAI account, workspace, privacy, retention, and data-control settings. The plugin instructions advise users not to include unnecessary personal or sensitive student information.

The public source repository is hosted by GitHub. Visiting or interacting with GitHub is subject to GitHub's own privacy terms. Support requests submitted through GitHub Issues are public unless GitHub or the repository owner indicates otherwise; users should not include student data or confidential institutional information.

For privacy questions, open a support issue without including confidential information: https://github.com/trannhuquynh1010/AI-project/issues
