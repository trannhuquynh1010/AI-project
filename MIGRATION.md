# Continue development on another computer

## Clone

```text
git clone https://github.com/trannhuquynh1010/AI-project.git natural-science-learning-design
cd natural-science-learning-design
```

## Important paths

- `.codex-plugin/plugin.json`: plugin manifest.
- `skills/review-khtn-lesson-plan/SKILL.md`: main workflow instructions.
- `skills/review-khtn-lesson-plan/references/`: condensed CBCI, KUD, IBL, Structure of Knowledge/Process and lesson-observation references.
- `submission/`: public-submission notes and test cases.
- `assets/`: listing icons.
- `dist/`: ready-to-transfer ZIP package.

## Verify after cloning

```text
git status
git log --oneline -5
```

The official source documents and teacher lesson plans are intentionally kept outside this public repository. Copy them separately only when authorized.
